# v1.32.0｜2019 春季首批 TV 目錄 QA

本記錄描述 repository source 與本機驗證；正式部署須在固定版本合併後獨立驗收。

## 資料範圍

- 新增《鬼滅之刃 竈門炭治郎 立志篇》、《一拳超人 第二季》、《請讓我撒嬌，仙狐大人！》及《文豪Stray Dogs 第三季》，共 4 套 TV 作品、9 筆 OP／ED 及 3 筆官方音樂影片 metadata。
- 2019 春季頁與 API 明示部分收錄；2019 夏季維持 42 套作品及 103 筆歌曲，2025 秋季仍未收錄。
- 《一拳超人》第 2 季以 4 月 9 日正篇首播及星期二 25:35 分類，與 4 月 2 日回顧特番區分。《鬼滅之刃》TV 立志篇以 4 月 6 日首播分類，不以先行劇場上映日期代替。
- 《竈門炭治郎のうた》保留第 19 話插入歌兼片尾曲用途，並分開椎名豪的發行名義、中川奈美的演唱及 ufotable 作詞；用途由正式播出機構 ABEMA 與歌曲索引交叉核對，製作資料由動畫官方核對。
- 保留仙狐與シロ的角色演唱，以及《Lily》的兩筆編曲 credits；沒有把僅能證實為插入歌的曲目加入 OP／ED。
- 新作品省略未核對圖片；只記錄必要事實、公開來源與 2026-09-07 核對日期。三筆影片已核對官方渠道、標題與 oEmbed metadata，不下載或重新託管媒體。

## 本機驗收

- `npm run catalog:check`：7 個檔案、168 項通過。
- `CI=true npm run check`：完整流程通過，包括公開邊界、`npm audit --audit-level=low`、Astro check、266 項單元測試、build、Cloudflare dry-run 及 20 項 Playwright 測試；依賴稽核為 0 項漏洞。
- 建置產生 1,965 個 HTML 頁面，3,929 個公開產物通過邊界檢查；Wrangler 讀取 5,899 個 Static Assets，0 application bindings。
- 全目錄為 29 個季度快照、1,921 個唯一作品、4,238 筆 OP／ED 與 1,759 筆官方／正式授權影片 metadata。
- 對照 v1.31.1 建置，既有 1,945 份季度與作品 API 檔案逐位元相同；新增 4 份作品與 1 份季度檔案，只更新季度索引，沒有移除 API 檔案或改變 v1 契約。
- Chromium 1280px 與 390×844 實際操作年份目錄 → 春季 → 創作者搜尋中川奈美 → 第 19 話片尾曲；到達正確歌曲錨點，並顯示獨立演唱欄。另核對仙狐 OP 的兩筆角色演唱 credits。
- 上述畫面沒有水平溢出、頁面程式錯誤、錯誤覆蓋層、未經操作建立的 iframe 或 YouTube 媒體連線。
- 既有分頁、320px 窄螢幕、無 JavaScript 原生導覽、手機鍵盤、離線閱讀、404、圖片 fallback 與公開 API 錯誤邊界測試全部保留。資料量與分頁數斷言更新至新快照，仍限制每頁最多 12 套作品。
- 影片同意以受控播放器回應確認《一拳超人》第 2 季 ED 的正確 ID；未驗證實際 YouTube 播放、實體裝置、Safari、Firefox、Lighthouse／Core Web Vitals。
