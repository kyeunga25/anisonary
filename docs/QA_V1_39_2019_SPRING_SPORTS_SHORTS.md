# v1.39.0｜2019 春季運動作品與電視短篇 QA

本記錄描述 repository source 與本機驗證；正式部署須在固定版本合併後獨立驗收。

## 資料範圍

- 新增《八月的棒球甜心》、《超可動女孩 1/6》及《八十龜醬觀察日記》第一季，共 3 套 TV 作品（含電視短篇）、4 筆 OP／ED 與 2 筆官方影片 metadata。
- 春季快照共 26 套作品、59 筆歌曲；春、夏季仍在補充，2025 秋季尚未收錄。
- 作品身份、季度及首播日期保留繁中作品頁、歌曲索引與播出資料交叉來源；《超可動女孩 1/6》的日期另保留當年報導，未有充足第一方時段證據，時刻保留空值。原動畫網域的 HTTPS 證書無效，未新增為官方入口。
- 《八月的棒球甜心》依東京電視台原始資料歸入週日深夜編輯時段；只收錄 2019 年 TV 版歌曲，不納入後續追加集數或其他專輯收錄曲。
- 《どんなときも。》保留四位角色演唱者及製作公司列明的詞曲、編曲；完整版於 2019-06-17 先行配信，迷你專輯為 2019-08-09。《エチュード》單曲為 2019-05-22，TV Size 為 2019-05-01。
- 《それゆけ！恋ゴコロ》依藝人官方 MV 與 AT-X 資料核對為 OP，沒有沿用第三方唱片頁的 ED 標示。《ONE》依正式發行 metadata 保留 2019-04-27 數位日期；編曲未取得足夠第一方證據，保留空值。
- 《八十龜醬觀察日記》保留第一季首三話的官方時段變更；OP／ED 用途尚不足以完成核對，沿用歌曲待補充狀態，不以後續季度或一般主題歌填入。
- 每首歌曲保留第一方、交叉來源、語言及 2026-09-07 核對日期。完整 MV 與官方音源分開分類；沒有新增圖片、下載媒體或自動播放。

## 本機驗收

- `npm run catalog:check`：7 個檔案、196 項通過。
- `CI=true npm run check`：公開邊界、依賴稽核、Astro check、294 項單元測試、build、Cloudflare dry-run 及 31 項 Playwright 測試全部通過；`npm audit --audit-level=low` 為 0 項漏洞。
- 建置產生 1,987 個 HTML 頁面，3,973 個公開產物通過邊界檢查；Wrangler 讀取 5,965 個 Static Assets，0 application bindings。
- 全目錄為 29 個季度快照、1,943 個唯一作品、4,288 筆 OP／ED 與 1,786 筆官方／正式授權影片 metadata。
- 對照 v1.38.0，1,969 份既有 API JSON 逐位元相同；只更新春季清單及新增 3 份作品檔案，沒有移除。
- Chromium 1280px 與 390×844 核對年份目錄 → 春季、編曲者搜尋 → 翻唱歌曲、完整署名、TV Size 日期、電視短篇、官方影片版本與歌曲空狀態，共 16 個操作畫面。
- 畫面沒有水平溢出、頁面程式或 CSP 錯誤、錯誤覆蓋層；明確操作前沒有 iframe 或 YouTube 媒體連線。
- 既有影片同意、星期篩選、分頁、無 JavaScript 導覽、完整來源清單、離線、404、圖片 fallback 與 API 錯誤邊界回歸測試通過。
- 未驗證實際 YouTube 播放、實體裝置、Safari、Firefox、Lighthouse／Core Web Vitals。
