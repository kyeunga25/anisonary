# v1.49.2｜手機首頁入口 QA

核對日期：2026-09-08。本文件記錄 source 範圍；正式部署須於固定版本合併後獨立驗收。

## 介面範圍

- 760px 以下的首頁直接顯示介紹、季度／年份瀏覽與搜尋入口，縮短上下間距；裝飾示意圖在較大版面持續顯示。
- 全部介紹、來源狀態、動畫卡片及目錄連結保留。全域導覽維持 5 個入口，原生年份／季度連結支援無 JavaScript 操作。
- 只調整首頁樣式與對應回歸；沒有變更歌曲、來源、日期、識別碼、搜尋索引、API、資料模型或部署架構。

## 畫面與操作

- 在本機 390×844 視窗中，搜尋入口由約 886px 提前至 387px，當季動畫標題由約 1,121px 提前至 598px；320px 及 760px 版面也能在首屏看到介紹與三個操作入口。
- 960px 與 1280px 的主要元素位置保持一致；首頁在 320、390、760、761、959、960、1040、1100、1101、1200、1280px 的既有範圍檢查通過。
- 新增回歸驗證淺深色、鍵盤進入搜尋、搜尋結果、瀏覽器返回、年份／季度導覽，以及 390px 無 JavaScript 的原生連結。
- 16 個畫面涵蓋淺深色、320／390／760／761／960／1280px、展開手機選單及無 JavaScript 閱讀；沒有水平溢出、頁面錯誤、提前建立 iframe 或 YouTube 請求。人工檢視淺深色手機首頁及選單截圖。
- 既有對比回歸依顯示狀態檢查裝飾標籤，繼續量度手機與桌面的實際來源、導覽、歌曲 OP／ED、搜尋提示及互動文字。
