# v1.41.1｜動畫名稱顯示 QA

本記錄描述 repository source 與本機驗證；正式部署須在固定版本合併後獨立驗收。

## 修正範圍

- 作品頁、季度卡片、搜尋結果、連結標籤及結構化資料共用名稱顯示規則：日文原名保留，其他欄位只有與已顯示名稱不同時才加入。
- 《おどるモワイくん》的繁中欄沿用日文原名，現在只顯示一次原名，另保留 `Odoru Mowai-kun`；《SELECTION PROJECT》的三個相同名稱合併顯示，`PLUTO ～冥王～` 等不同寫法則保留。
- 只比較完全相同的文字，不合併大小寫、字形或標點不同的名稱，也不生成新譯名。原始目錄欄位、來源、核對日期、搜尋索引資料與 API 契約保持不變。
- 作品頁與季度卡片由靜態 HTML 呈現相同規則；搜尋沿用瀏覽器內的索引及篩選。頁面標題、分享標題與 JSON-LD 同步省略重複名稱。
- 補齊 v1.40.1、v1.40.2 及 v1.41.0 既有 source 改動的 Changelog 摘要，內容依對應 QA 記錄整理。

## 本機驗收

- `npm run catalog:check`：7 個檔案、203 項通過。
- 完整品質流程的各項門檻通過：公開邊界、開發及正式依賴稽核、Astro check、301 項單元測試、build、Cloudflare dry-run 及 34 項 Playwright 測試；兩種依賴稽核均為 0 項漏洞。
- 本機 E2E 使用獨立預覽連接埠及輸出位置，保留原有測試內容與時限；單一 worker、沒有重試，34 項一次通過。既有搜尋私隱、手機鍵盤、影片同意、離線、404、來源展開與圖片 fallback 驗證均保留。
- 建置保留 1,989 個 HTML 頁面，3,977 個公開產物通過邊界檢查；Cloudflare dry-run 沒有 application bindings。
- 對照同一環境的 v1.41.0 建置，1,975 份 API 檔案逐位元相同，沒有新增、移除或改動。
- Chromium 在 1280×900、390×844 核對作品頁、季度卡片與 Romaji 搜尋，另核對無 JavaScript 的手機作品頁，共 13 個畫面／導覽檢查；修正前 11 個檢查畫面有重複名稱，修正後為零，沒有水平溢出、頁面程式錯誤或未經操作建立的 iframe。
