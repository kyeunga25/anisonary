## 本機驗收

- `npm run catalog:check`：7 個檔案、172 項通過。
- `CI=true npm run check`：公開邊界、依賴稽核、Astro check、270 項單元測試、build、Cloudflare dry-run 及 22 項 Playwright 測試全部通過；`npm audit --audit-level=low` 為 0 項漏洞。首次稽核因服務 TLS 連線中斷未完成，重試後完整流程通過。
- 建置產生 1,969 個 HTML 頁面，3,937 個公開產物通過邊界檢查；Wrangler 讀取 5,911 個 Static Assets，0 application bindings。
- 全目錄為 29 個季度快照、1,925 個唯一作品、4,247 筆 OP／ED 與 1,762 筆官方／正式授權影片 metadata。
- 對照 v1.32.1 建置，1,950 份既有 API 檔案逐位元相同；只更新春季清單並新增 4 份作品檔案，沒有移除檔案。第二季《我們真的學不來！》的既有 API 內容完全相同，API v1 契約不變。
- Chromium 1280px 與 390×844 實際操作年份目錄 → 春季 → 搜尋角色演唱者 → 第 6 話片尾；確認四位演唱者及歌曲錨點。另檢查 Study 第一季三位角色演唱者及桌面／手機排版。
- 畫面沒有水平溢出、頁面程式或 CSP 錯誤、錯誤覆蓋層、未經操作建立的 iframe 或 YouTube 媒體連線。手動預覽曾使用舊建置的 headers，重新啟動預覽以讀取最新 headers 後重驗通過。
- 保留分頁、320px 窄螢幕、無 JavaScript 原生導覽、星期篩選、手機鍵盤、離線閱讀、404、圖片 fallback 及 API 錯誤邊界測試。新增官方影片的明確同意流程以受控播放器回應驗證正確 ID。
- 未驗證實際 YouTube 播放、實體裝置、Safari、Firefox、Lighthouse／Core Web Vitals。
