# v1.43.0｜獨立作品識別 QA

核對日期：2026-09-07。本文件記錄 source 範圍與本機驗證；正式部署須於固定版本合併後獨立驗收。

## 調整範圍

- 新作品可使用穩定的 `catalog-` 本站識別碼，必須提供作品識別來源、語言與實際核對日期；不要求取得外部索引 ID。
- 季度、跨季引用、OP／ED 來源及影片共用識別碼；數字型既有 key 與本站 key 分開，禁止混用、重複、錯誤歸屬、無效來源及日期。
- 未核對的外部連結、繁中名與 Romaji 名稱可以省略，保留原文搜尋與既有 API v1 契約。
- 作品識別來源只輸出允許欄位。測試用虛構記錄留在 unit fixture，不加入公開目錄、API 或頁面。
- 本切片沒有新增作品、歌曲、媒體、後端或 runtime database binding。

## 本機驗收

- `npm run catalog:check`：219 項通過。
- `npm run check`：公開邊界、Lint、317 項單元測試、建置、Cloudflare dry-run 及 36 項 Playwright 測試通過；最終瀏覽器測試沒有重試。
- 完整依賴與正式依賴稽核均為 0 項漏洞；`fast-uri` 保持 3.1.6，既有安全回歸測試通過。
- 1,976 份 API 與 v1.42.1 source 逐位元相同，沒有新增或移除。建置保留 1,990 份 HTML 與 3,979 份公開產物；dry-run 沒有 runtime bindings。
- 12 項識別測試涵蓋跨季與重複 ID、命名空間、長度、無效或含憑證的來源、實際日曆日期、歌曲來源與影片歸屬、API 讀回、缺少別名時的搜尋，以及未知編輯欄位過濾。
- 識別關聯與未知欄位測試均先確認原有行為會失敗，再驗證修正；既有季度名稱的回歸要求保持不變。
- Playwright 覆蓋桌面及手機導覽、年代／年份／季度目錄、本機搜尋、鍵盤、無 JavaScript 閱讀、影片明確操作後載入、離線、404 及錯誤狀態。

## 發布界線

本機與分支建置結果不代表正式網站已更新。發布時仍須核對合併 SHA、CI、Cloudflare 實際版本與流量，以及 live routes、headers、API 與產物內容。本切片未驗證實體裝置、Safari、Firefox、Lighthouse／Core Web Vitals 或實際 YouTube 播放。
