# v1.38.0｜2019 春季角色歌曲與分割季度 QA

本記錄描述 repository source 與本機驗證；正式部署須在固定版本合併後獨立驗收。

## 資料範圍

- 新增《進擊的巨人》第三季 Part.2、《異世界四重奏》第一季與《南無阿彌陀佛!-蓮台 UTENA-》，共 3 套 TV 作品（含電視短篇）、7 筆 OP／ED 與 3 筆官方影片 metadata。
- 春季快照共 23 套作品、55 筆歌曲；2019 春、夏季仍在補充，2025 秋季尚未收錄。
- 依官方第一季存檔、唱片公司及製作方原始公告核對 TV 首播日、深夜編輯時段與先行網絡配信；繁中名稱保留逐作品交叉來源，沒有新增未核對圖片。
- 《進擊的巨人》第三季後半保留獨立 OP／ED，不納入前半歌曲或單曲其他收錄曲。《憧憬と屍の道》的 TV Size 於 2019-04-29 先行配信，完整版單曲為 2019-06-19；《Name of Love》完整版於 2019-04-29 先行串流，CD 為 2019-05-29。
- ED 依官方音樂總覽、單曲頁正文及藝人公告交叉確認，沒有沿用單曲頁 HTML 標題中殘留的前半曲名。保留正式發行 metadata 的英文共同詞曲署名；編曲來源有差異，未推定或合併填入。
- 《異世界四重奏》OP 與一般 ED 保留各自四位角色演唱者；《Hollow Veil》依 KADOKAWA 發行資料與 ABEMA 證明保留為第 5 話特別 ED，並記錄兩位作詞者。八月單曲收錄日期不改變春季動畫用途。
- 《ルビー》保留動畫 ED 與 2019-01-15 數位發行日，另註記三月專輯日期；《天唄》未有足夠第一方日期證據，保留空值。原動畫網域無法解析，沒有新增為官方入口。
- 官方完整音源、短版 MV 與 lyric video 分開分類；沒有下載、重新託管或自動播放媒體。每首歌曲保留第一方、交叉來源、語言與 2026-09-07 核對日期。

## 本機驗收

- `npm run catalog:check`：7 個檔案、192 項通過。
- `CI=true npm run check`：公開邊界、依賴稽核、Astro check、290 項單元測試、build、Cloudflare dry-run 及 30 項 Playwright 測試全部通過；`npm audit --audit-level=low` 為 0 項漏洞。
- 建置產生 1,984 個 HTML 頁面，3,967 個公開產物通過邊界檢查；Wrangler 讀取 5,956 個 Static Assets，0 application bindings。
- 全目錄為 29 個季度快照、1,940 個唯一作品、4,284 筆 OP／ED 與 1,784 筆官方／正式授權影片 metadata。
- 對照 v1.37.1，1,966 份既有 API JSON 逐位元相同；只更新春季清單及新增 3 份作品檔案，沒有移除。
- Chromium 1280px 與 390×844 核對年份目錄 → 春季、創作者搜尋 → 特別片尾、兩組角色合唱、分割季度、完整串流日期及 lyric video，共 16 個操作畫面。
- 畫面沒有水平溢出、頁面程式或 CSP 錯誤、錯誤覆蓋層，明確操作前沒有 iframe 或 YouTube 媒體連線。新增瀏覽器測試另覆蓋 960px 與 320px。
- 既有影片同意、星期篩選、分頁、無 JavaScript 導覽、完整來源清單、離線、404、圖片 fallback 與 API 錯誤邊界回歸測試通過。
- 未驗證實際 YouTube 播放、實體裝置、Safari、Firefox、Lighthouse／Core Web Vitals。

## 發布界線

本機與 GitHub CI 通過不等於正式部署完成。發布時須核對固定 SHA、Workers Builds 正式部署與流量、live routes、headers、API 及產物內容；對應 GitHub Release 保留正式驗收摘要。
