# v1.42.1｜作品資料響應式排列 QA

核對日期：2026-09-07。本文件記錄 source 範圍與本機驗證；正式部署須於固定版本合併後獨立驗收。

## 修正範圍

- 521–760px 的無圖作品頁曾套用海報雙欄設定，內容被壓入 128px 欄位。現在無圖作品在此範圍維持全寬，有圖作品保留海報配置。
- 長播出說明不再擠壓「播出」或「資料審閱」標籤；手機資料值按欄位對齊，長內容正常換行。
- 直向基本資料列及手機外部連結移除殘留的桌面分隔線；桌面橫向排列仍有分隔線。
- 保留原始動畫、歌曲、創作者、來源、搜尋索引與 API 資料，不改動媒體連線同意及離線策略。

## 本機驗收

- `npm run catalog:check`：207 項通過；`npm run check`：公開邊界、Lint、305 項單元測試、建置、Cloudflare dry-run 及 36 項 Playwright 測試通過，最終瀏覽器測試沒有重試。既有搜尋、影片同意、離線、404 及圖片 fallback 回歸通過。
- 完整依賴與正式依賴稽核均為 0 項漏洞。建置保留 1,990 份 HTML 與 3,979 份公開產物，dry-run 沒有 runtime bindings。

- 1,976 份 API 與前一 source 版本逐位元相同，沒有新增或移除。
- Chromium 在 1280、960、760、640、521、520、390 及 320px 檢查五套有圖／無圖作品，另以無 JavaScript 核對 640、390px，共 50 個畫面；沒有水平溢出、頁面程式錯誤、框架錯誤畫面或提前建立的 iframe。
- 同一批修正前後量測中，標籤拆行由 24 個畫面降至 0，無圖內容錯誤縮窄由 12 降至 0，直向版型殘留分隔線由 40 降至 0。這些是所選畫面的結果，不代表已逐頁測試整個目錄。
- 《THE ORIGIN》在 640px 的作品內容寬度由 128 增至約 589px，資料區高度由約 887 降至 360px；390px 的標籤與內容對齊，1280px 保留原有橫向排列。人工檢視這三個尺寸的截圖。
- 定向回歸測試在修正前重現標籤拆行，修正後通過；涵蓋斷點兩側、有圖／無圖內容、標籤可讀性、影片未載入狀態，以及無 JavaScript 時以鍵盤回到季度頁。
- 視覺量測停用 Service Worker，僅出現 Playwright 阻止其註冊的預期警告；離線功能由既有獨立 E2E 驗證。

## 發布界線

本機與分支建置結果不代表正式網站已更新。發布時仍須核對合併 SHA、CI、Cloudflare 實際版本與流量，以及 live routes、headers、API 與產物內容。本切片未驗證實體裝置、Safari、Firefox、Lighthouse／Core Web Vitals 或實際 YouTube 播放。
